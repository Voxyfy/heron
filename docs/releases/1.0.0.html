Heron 1.0.0

The first release. A scratchpad for PHP and Laravel: write a few lines, press ⌘R, see every value as a card.

Run

  • Runs inside your Laravel or plain PHP project with the PHP on your Mac (Herd, Homebrew), or with no project at all.
  • Servers over SSH: saved connections in groups, password or key sign-in, the snippet runs inside the remote project with its PHP.
  • Tidy on run: indentation, spacing and missing semicolons fixed first. Errors and warnings appear on their line.

See

  • Every dump() and the last expression as a card; table view and CSV export for lists of rows.
  • SQL queries a snippet ran, and the project's storage/logs with level filters, search and live reload.

Write

  • Completion that knows your models: classes with their use line, columns, relations, scopes, functions, variables; callables bring their parameters as placeholders.
  • Tabs, history, snippets (shared per project), an open-anything palette, five themes, English and Turkish.
